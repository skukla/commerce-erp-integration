Default Config applies to every website unless a website changes it. Untick Use Default Value to change a setting for this website only.

Orders

Send orders to the ERP

Create each order in the ERP and bring its order number back.

Orders placed on this website are created in the ERP, and the ERP’s order number is written back. With several ERPs, an order is split: each ERP gets only the lines for the products it owns.

Hold orders while the ERP is offline

Send them when it’s back, instead of dropping them.

An order placed while the ERP is offline is sent when the ERP is back (tried again for up to a day). When off, such an order is not sent.

Order status when the ERP confirms

Leave empty to add a note only.

A status to set on the Commerce order when the ERP confirms it. Create it at Stores › Settings › Order Status and assign it to the Pending state (not as its default). No status can move an order to Processing; Commerce does that itself when the order is invoiced or shipped.

Sales organization

Every ERP uses these unless it sets its own.

Sales organization

The ERP’s code for this website’s sales, e.g. 1000.

Four letters or digits, like an SAP sales organization. Orders from this website carry it. An ERP that sets its own uses that instead.

Sales organization name

What the ERP calls it. Empty: the website’s name.

What the ERP calls that sales organization. When empty, the ERP prints the website’s name.

Products and order numbers

Products this ERP owns

Which products this ERP sells and ships.

All products: every product (one ERP only). Inventory sources: the products stocked in the sources named below. Attribute: the products whose attribute names this ERP. When not set: products whose erp_owner is northwind.

Inventory sources

Source codes, comma-separated.

The inventory source codes this ERP ships from, as default, east. Used with “Products in these inventory sources”.

Product attribute

An attribute and value, as erp_owner=northwind.

A product attribute and the value that names this ERP. Used with “Products whose attribute names this ERP”.

Prefix on ERP order numbers

Shown in Commerce as NORT-0000001013.

Put in front of the ERP order number written onto Commerce orders, so two ERPs on one store tell their orders apart. One to six capital letters or digits. Empty: the first four letters of the ERP’s name (NORT).

Products and order numbers are set once for every website. Switch to Default Config to change them.
