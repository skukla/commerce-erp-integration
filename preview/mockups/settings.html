Orders

Send orders to the ERP

Create each order in the ERP and bring its order number back.

An order with products from both ERPs is split: each ERP gets only its own lines, and each ERP order number is written onto the Commerce order.

Hold orders while the ERP is offline

Send them when it’s back, instead of dropping them.

A held order is retried for up to a day. It shows under Needs attention on the Overview until it goes through, and you can re-send it yourself.

Order status when the ERP confirms

Leave empty to add a note only.

The list shows the statuses assigned to the Pending state in Stores › Settings › Order Status. The order moves to Processing only when it is invoiced or shipped, as Commerce always does.
